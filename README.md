# 코오롱글로벌·하늘채 커뮤니티 통합 모니터링 시스템 (KolonMonitor)

네이버(카페, 블로그), 다음/카카오(카페, 블로그, 게시판), 주요 커뮤니티(뽐뿌, 디시인사이드, 클리앙, 에펨코리아, 블라인드 등) 및 포털 뉴스에서 **코오롱글로벌**과 주거 브랜드 **하늘채** 관련 최신 게시글을 실시간으로 자동 수집하고, 건설/시공 특화 리스크(하자, 누수, 균열, 부실시공, 입주지연 등)를 조기에 감지하여 알림을 제공하는 전문 모니터링 프로그램입니다.

## 🌟 주요 기능 (Key Features)

### 1. 멀티 채널 실시간 수집 엔진 (Multi-Channel Crawlers)
- **별도 유료 API 없이도 즉시 구동**: 비로그인/무설치 상태에서도 고신뢰 웹 크롤러로 실시간 데이터 수집
- **네이버 (Naver)**: 최신 탭 구조(`ssc=tab.cafe.all`, `ssc=tab.blog.all`) 기반 네이버 카페 및 블로그 실시간 최신순 수집
- **다음/카카오 (Daum/Kakao)**: 다음 카페, 블로그, 게시판의 구조화된 데이터 컴포넌트(`c-card`) 파싱으로 100% 누락 없는 수집
- **주요 커뮤니티**: 디시인사이드(부동산 갤 등), 뽐뿌, 클리앙, 에펨코리아, 블라인드 등 주요 커뮤니티 타겟 수집
- **언론/뉴스**: 포털 뉴스 및 구글 뉴스 RSS 실시간 기사 수집
- **공식 Open API 듀얼 지원**: 네이버 검색 API(Client ID/Secret) 및 카카오 REST API 키 등록 시 공식 API 병행 수집

### 2. 건설/시공 특화 리스크 및 감성 분석 (Risk & Sentiment Analysis)
- **건설/부동산 맞춤형 리스크 사전 내장**:
  - 🚨 **심각 (High Risk, 80~100점)**: 부실시공, 철근누락, 붕괴, 균열/크랙, 누수, 침수, 중대재해, 추락사, 압수수색, 영업정지, 고발, 소송, 비대위, 분쟁, 입주지연, 공사중단
  - ⚠️ **주의 (Medium Risk, 50~79점)**: 마감불량, 하자, 곰팡이, 결로, 악취, 미분양, 분양가논란, 공사소음, 민원, 설계변경, 옵션장사
  - ℹ️ **관심/긍정 (Positive)**: 랜드마크, 대장아파트, 프리미엄, 입주축하, 완판, 청약대박, 우수시공, 수주성공, 신고가
  - ✅ **안전/중립 (Safe/Neutral)**: 단순 분양안내, 모델하우스 위치, 청약일정, 주식 공시
- **스마트 노이즈 필터링**: "하늘채 한정식", "하늘채 쌈밥", "고깃집", "펜션" 등 부동산/건설과 무관한 동음이의어 자동 필터링

### 3. 고속 데이터베이스 및 중복 방지 (SQLite WAL Engine)
- SQLite 기반 경량 고성능 로컬 데이터베이스 탑재 (동시성 높은 WAL 모드 적용)
- URL 정규화 및 SHA-256 해시 기반으로 동일 게시글의 **중복 수집 및 중복 알림 원천 차단**

### 4. 실시간 자동 스케줄러 & 다채널 알림 (Automation & Alerting)
- **APScheduler 백그라운드 스케줄러**: 5분 / 15분 / 30분 / 1시간 주기 자동 모니터링
- **Windows 바탕화면 토스트 알림**: 주의/심각 수준의 리스크 게시글 감지 시 윈도우 우측 하단에 즉각 팝업 알림
- **텔레그램 봇 알림**: 봇 토큰 및 Chat ID 설정 시 지정된 텔레그램 대화방/채널로 긴급 알림 즉시 발송
- **브라우저 실시간 스트림 (SSE)**: 서버에서 새 글이 수집되는 즉시 대시보드 새로고침 없이 실시간 피드에 자동 반영

### 5. 직관적인 모던 웹 대시보드 (Modern Web Dashboard)
- **요약 KPI 카드**: 총 수집 건수, 오늘 신규 수집량, 주의 리스크 건수, 심각 리스크 건수
- **통계 분석 차트 (Chart.js)**: 최근 7일간 일자별 언급량 추이, 채널별 점유율 도넛 차트, 감성/위험도 분포 바 차트
- **실시간 피드 및 상세 모달**: 채널별 뱃지, 위험도 태그, 원문 링크 바로가기, 북마크 토글, 읽음 상태 처리
- **키워드 & 제외어 관리 모달**: 코오롱글로벌, 하늘채 아파트 및 특정 분양 단지명 추가/삭제, 제외어 관리
- **엑셀(.xlsx) 내보내기**: 현재 필터된 게시글 전체를 엑셀 파일로 즉시 다운로드

│   ├── __init__.py
│   └── sentiment.py            # 감성 분석, 건설 리스크 사전 및 점수 산출기

## 🚀 빠른 시작 (Quick Start)

### 1. 요구 사항
- Python 3.10 이상 (또는 `uv`)
- Windows 10 / 11 권장 (Windows Toast 알림 완벽 지원)

### 2. 설치 및 실행

#### 방법 1: `run.bat` 또는 `run.ps1` 더블클릭 (가장 간편함)
프로젝트 폴더 내 `run.bat` 또는 `run.ps1`을 실행하면 가상환경 및 의존성을 자동으로 감지하여 서버가 기동됩니다.

#### 방법 2: 명령줄(CLI)에서 직접 실행
```bash
# 1. 패키지 설치
uv pip install -r requirements.txt
# 또는
pip install -r requirements.txt

# 2. 애플리케이션 실행
python app.py
# 또는 uv 사용 시
uv run python app.py
```

### 3. 웹 대시보드 접속
브라우저를 열고 아래 주소로 접속합니다.
```
http://127.0.0.1:8000
```

## ⚙️ 설정 가이드 (Configuration)

웹 대시보드 상단의 **[설정]** 버튼을 눌러 브라우저에서 편리하게 설정할 수 있습니다.

1. **자동 수집 주기**:
   - `5분`, `15분`, `30분`, `1시간` 중 원하는 주기를 선택할 수 있습니다.
2. **Windows 토스트 알림**:
   - 체크 시 주의(⚠️) 및 심각(🚨) 리스크 게시글이 감지되면 윈도우 우측 하단에 알림창이 팝업됩니다.
3. **텔레그램 알림**:
   - 텔레그램 `@BotFather`를 통해 생성한 Bot Token과 수신할 Chat ID를 입력하면 즉시 긴급 알림이 전송됩니다.
4. **키워드 관리**:
   - 상단 **[키워드 관리]** 버튼을 통해 특정 아파트 단지명(예: `산곡역 자이힐스하늘채`, `엄궁역 트라비스 하늘채` 등)을 수시로 등록/삭제할 수 있습니다.
   - 아파트와 무관한 식당, 펜션 등의 단어를 **제외 키워드**에 등록하여 노이즈를 완벽하게 차단할 수 있습니다.
